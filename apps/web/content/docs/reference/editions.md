# Editions and limits

**InfraMole Community** is free and open source — you run it on your own
server. It is a complete product, not a trial: there is no limit on servers
or VMs.

|                                                                            | Community                       |
| -------------------------------------------------------------------------- | ------------------------------- |
| Price                                                                      | Free forever                    |
| Licence                                                                    | **AGPL-3.0-only** (open source) |
| Servers and VMs                                                            | Unlimited                       |
| Workspaces                                                                 | 1                               |
| Discovery (agents, Azure, AWS, Cloudflare), map, dependencies, impact      | ✔                               |
| Two-factor authentication, passkeys, Google / Microsoft sign-in, audit log | ✔                               |
| Deployment                                                                 | Docker Compose                  |

## Planned editions

- **InfraMole Cloud** — we run and maintain InfraMole for you. Plans will be
  sized by servers and VMs only; applications, databases, containers,
  domains and discovered services stay unlimited.
- **InfraMole Business** — self-hosted, for larger teams and MSPs: several
  workspaces, a signed offline licence (no phone-home), priority support and
  a commercial licence as an alternative to the AGPL.

Interested in either? Write to [sales@inframole.com](mailto:sales@inframole.com).
